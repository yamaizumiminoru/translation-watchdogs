# ChatGPT おつかれ Watchdog

バージョン **0.1.5**。ChatGPTで明示的な一時エラーが出たときだけ、復旧をお手伝いするChrome拡張です。通常の会話・プロジェクト内の会話・GPTの会話に対応し、翻訳や特定のリポジトリに限定しません。

## 何をする？

- 会話ごとに「この会話を見守る」を押して開始します。初期状態はオフです。
- エラー表示が設定秒数（初期値5秒）続いたら、表示内容に合った復旧を行います。
- **ユーザーの送信が失敗してRetryが出た場合**は、元の依頼をRetryします。未受理の依頼に「続けて」だけを重ねて送りません。
- **回答途中に一時エラーが出た場合**は、「おつかれさまです👏🍵」を添え、エラーに合わせた再開依頼を送ります。翻訳用の指示やGitHubの参照先は挿入しません。
- **最新ターンのエラー表示に `Error in message stream` が出た場合**も対象にします。回答側の明示的なエラーなら再開依頼を送り、ユーザーの送信失敗でRetryが出た場合は元の依頼をRetryします。会話本文でその文言に言及しただけなら反応しません。
- **最新のassistantターンのエラー欄に `Resume stream unavailable` または `Stream cache expired` とRetryが並ぶ場合**は、追加の再開文を送らず、画面のRetryを1回だけ試します。本文内の引用、過去のエラー、Retryが離れた場所にある表示では発動しません。下書き・添付・ユーザー入力があれば操作せず、再読み込み後も同じエラーへのRetryを繰り返しません。
- 現在のChatGPTの `data-turn-key`、ユーザーメッセージの吹き出し、検索単位の役割表示からも最新ターンを識別し、同じターンの本文が増えても操作済み判定を維持します。
- ユーザー文と回答が同じ `data-turn-key` の枠に入る場合も両者を分離し、最新の回答のエラーだけを判断します。
- 最新のassistantターンに `Thinking failed` の失敗操作欄が出た場合も対象です。回答中表示が消え、エラーが初期値5秒間続いたときだけ、1回の再開依頼を送ります。本文中の引用や、完成済み回答に残った古い表示では発動しません。
- 自動入力で発生した入力イベントをユーザー操作と誤認せず、現在の `composer-submit-button` も送信ボタンとして認識します。ユーザー自身が入力を始めた場合の送信停止は維持します。
- 通常の返答完了、考え中、表示の点滅、しばらく本文が変わらない状態だけでは反応しません。
- 入力中の文章や添付ファイルを保護します。停止ボタンの自動クリックや、新しい会話への引き継ぎは行いません。
- 同じ会話を複数タブで開いている場合も、復旧操作が重複しないようにします。
- 同じ事象に対する繰り返し操作を抑止します。繰り返し失敗や対応できないエラーでは確認待ちになります。自動復旧は1会話につき初期値10回までです。

「翻訳おつかれ Watchdog」とは**別の拡張**です。既存の翻訳用拡張のファイルや設定は変更しません。ただし、**同じ会話で両方の見守りを有効にしないでください**。それぞれが復旧操作を送信する可能性があります。

## インストール

Chromeへの読み込み用には、[汎用版 ZIP](../dist/chatgpt-error-watchdog-0.1.5.zip) を展開するか、この `chatgpt-error-watchdog/` フォルダーを使用できます。選ぶフォルダーの直下に `manifest.json` があることを確認してください。

1. ZIPを使う場合は、まず展開します。展開したフォルダーの中に `manifest.json` があることを確認します。
2. Chromeで `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」から、**展開したフォルダーまたはこの `chatgpt-error-watchdog/` フォルダー**を選びます。ZIP自体や、既存の翻訳用拡張フォルダーは選びません。
4. すでに開いていたChatGPTタブは一度再読み込みします。
5. 見守りたい会話で拡張のポップアップを開き、「この会話を見守る 👀」を押します。

フォルダーはChromeが継続して読み込める場所に置いてください。更新時は同じフォルダーのファイルを更新し、拡張機能カードの再読み込みボタンを押してから、ChatGPTタブも再読み込みします。

## 設定と状態

ポップアップの「設定」で、エラー確認の待機秒数と自動復旧回数の上限を変更できます。設定値は全会話で共通、見守りのオン・オフと回数は会話ごとです。ポップアップの状態表示は約2秒おきに更新します。

「入力内容を保護して待機中」なら、入力欄や添付を確認してください。「確認が必要です」「自動復旧を休止中」なら、状態欄の理由を確認し、元のエラーを解決してから再開してください。上限を増やしたり見守りを再開したりするだけで、サービス側の問題が直るわけではありません。

ポップアップを閉じても見守りは続きます。ただし、PCのスリープ中、Chromeが停止している間、タブが破棄・凍結されている間は動作できません。バックグラウンドタブではChromeの制御により確認が遅れる場合があります。

## 権限と動作範囲

ChatGPTページの画面上のエラー・入力欄・ボタンを読み取り、見守りを有効にした会話で、画面上のRetryボタンまたは入力欄と送信ボタンを使います。ChatGPTの非公開APIには接続しません。設定と監視状態はChrome拡張のローカルストレージに保存します。

ChatGPTの画面構造が変わると検出や復旧が動かなくなることがあります。実際の復旧完了はChatGPTの回答が再開したことを確認してください。

## 開発時の確認

このフォルダーで実行します。Windows PowerShellでは `npm.cmd` を使えます。

```powershell
npm.cmd ci
npm.cmd test
npm.cmd run check
```

テストは `node --test tests/*.test.cjs` による検出・判断・復旧の回帰テストです。`check` はJavaScriptの構文を確認します。画面を模したテストの成功は、実際のChatGPTで復旧成功を確認したことを意味しません。
